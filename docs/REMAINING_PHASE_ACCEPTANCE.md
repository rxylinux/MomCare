# 后续阶段的验收边界

执行顺序以 `DELIVERY_STATUS.md` 为准。此文件由 Codex 维护，细化 B2a 之后的既定第一版范围；不授权提前部署，也不将暂缓工具纳入首版。各阶段的具体文件与接口在上一阶段冻结后交给 ZCode，避免同时改写共享模块。

## B2b：产检、待产包与报告原件

复用 B2a 已验收的成员身份、分页、持久待办、revision 和冲突协议，贯通原有页面及其真实处理器。

- 产检：共同日期/时间、医院、项目勾选、陪同、材料、问题；保存操作者。调整孕期日期只影响可确认的未完成自动模板安排，手动改期、已完成、跳过和同周多条历史不覆盖。模板初始化须显式触发，双方同时初始化不重复。倒计时为应用内信息，不声称已订阅微信推送。
- 待产包：用稳定项目 ID，名称、数量、分类、存放位置、负责人、准备状态。旧 `hospital_bag_items` 无成员归属，不能在冷启动直接读取或自动迁入；与旧健康键一样保留原件到 B3。演示使用独立键。清单变化通过云同步，不能靠组件 deep watch 静默写旧键。模板生成幂等；关联共同任务由 C 继续实现，不复制完成进度。
- 报告：现有拍照/相册、列表、详情、批量分类入口接入同一云数据源。复用 B1 受控暂存→正式副本→登记，原件清晰可读；不默认以 quality 20 压缩替代原件。一个报告可对应多张图片，图片顺序稳定；报告信息包括日期/类型/上传者/稳定文件引用，暂时 URL 不持久化。
- 上传队列按成员持久化本地实体文件与稳定 uploadId；选择新图片用新 ID。同一批部分成功后只重试失败项，页面切换/重启/登记响应丢失不能重复建报告。空间不足、文件缺失、取消、权限拒绝均保留真实失败状态。
- 归档/改分类不遗失其他报告字段或附件；并发修改走冲突路径。删除先写 tombstone，立即禁止新下载/AI，再可恢复地清理实体文件；其他端旧缓存不得复活记录。多个报告引用同文件时按实际引用保护，不盲删。
- 暂存/孤立文件清理仅处理超过保留期且无进行中任务、无正式引用的对象；清理失败可重试，不能和正在登记的上传抢删。默认不配置自动云任务；先提供可测试的清理动作和部署期配置说明。
- AI 在配置/真实验证前明确未启用。报告内容不可仅凭 OCR 文本或格式错误结果标“分析完成/全部正常”。仅接通保存原件不等于 DeepSeek 已可用。

独立 review 覆盖同项目并发修改、模板重复点击、已有产检历史保留、部分批次失败重试、跨身份挂起上传、删除与读取/登记竞态、永久引用与临时 URL 分离，以及真实页/组件处理器。服务端 SDK 文件失败形状仍按官方与已锁定版本源码核对，本地验证不替代最后的真云验证。

## B3：旧数据确认、完整备份和隔离恢复

先完成可运行实现与合成数据验证；真实旧记录和真实备份在最终部署阶段由用户确认后处理。

1. **来源确认**：逐类列出旧健康、报告、待产包等数据来源与数量，保留原始字节备份。明确哪些是示例、哪些是本人旧数据；未确认不上传。私人心情/症状/备注由本人确认作者，不随健康数字自动共享。无法确定他人私人归属的记录保留隔离，不提供冒认另一成员的导入接口。
2. **迁移可恢复**：持久迁移批次、源 ID→目标 ID、内容摘要与附件映射。重复导入或中断重试不重复记录；修改过的源数据需重新预览确认，不能复用旧摘要当完成。任何旧云文件获取都需现有授权；不能让云函数下载任意 URL 作为迁移代理。
3. **完整导出**：共享记录默认包含，私人记录仅可选择调用者本人。保留 schemaVersion、导出范围、记录数、逐文件大小/摘要、稳定记录与附件映射以及**附件实体**。只有 JSON + fileID/临时 URL 不算完整备份。缺附件或中途失败必须标为不完整，不能显示可完整恢复。
4. **一致性说明**：导出期间另一端修改时，可采用受控重试或明确版本清单，不能混合不存在的一致性承诺。删除/撤回后不得经历史去重快照、迁移映射或导出接口重新泄露原文。服务端按调用者重新鉴权，客户端勾选范围不是授权。
5. **隔离恢复**：先校验版本、清单、大小/数量上限、摘要、重复路径、路径穿越与附件映射，再预览将恢复的记录/冲突。恢复到新的隔离命名空间用于验收，不默默覆盖当前云档案；已存在/较新/已删除记录必须明确解决。新环境不得信任备份自带 OpenID/owner/family 或外部 fileID，身份由当前受控流程确认，文件重新登记。
6. **平台路径**：选择微信小程序实际支持的本地文件保存/选择/导出途径；H5 预览可另用适配器，但不能以浏览器下载成功代替小程序产物。大附件按文件处理，不把全量原件塞进同步 KV 存储或一个无上限 JSON。包格式与平台 API 在实现时核对，附恢复操作说明。

验收要实际导出一个包含多张合成附件的样例、重新加载恢复、逐文件比较摘要并打开图片；测试损坏/缺附件/未知 schema/重复导入/超限/跨成员/private canary/中断续办。原输入和备份原件不被自动删除。

## C：双首页、分享与共同任务

遵循 DESIGN 的两个首页顺序，所有工具对双方开放；视角偏好与身份分开存放。新增字段用已验收的同步协议。

- 私人记录不自动分享。分享编辑器只包含用户明确确认的短句、目标日期；空分享不推断情绪，历史不冒充今日。
- 一项需求对应至多一个关联任务。接单和创建任务必须原子且唯一；重复点击、两端竞争和超时重放不重复。负责人和实际操作者分别保存，指派不等于对方接受。
- 作者可改/结束/撤回共享；撤回与任务内容清除具有可验证的一致性。旧客户端待办、任务复制标题、幂等结果、分页/冲突响应均不能使撤回正文复活。离线已看过的内容不能承诺立即远程擦除。
- 任务 pending/doing/done/cancelled 支持完成/撤销完成/取消，记录操作者和时间。产检/待产包以稳定 source ID 关联同一任务，完成状态按明确权威实体更新，避免双方各有一套进度。
- 首页/我的都有可用工具入口；已验收的健康、产检、报告、待产包可用，未实现计算器不提供空壳入口。知识按视角调整排序，文案不冒充当前身体状况；真实来源缺失就如实标明，不虚构医生认证。

验收妈妈分享→爸爸接下→完成、任意成员切两视角、长文本/空状态、跨上海午夜过期、撤回与正在接单/导出/重放竞态、待产包重复创建任务。对两个身份分别注入私人 canary 检查所有响应与可见状态。
