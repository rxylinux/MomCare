# 孕期食谱功能 起草稿（审阅版）

> **状态：2026-10-02 已实施**——92 道/11 营养素/5 周段已落为 `static/data/pregnancy-recipes.json` + `pages/tools/recipes.vue`（含今日三餐轮换）；数值经 DRIs 2023 联网核对 + 《孕期妇女膳食指南》全文二次校验；五套口径（鱼类/喝汤/早餐/碘盐/带饭）随条目落库。回归：`tests/phase-recipes.regress.cjs`（20 断言组）。

> **定位**：新功能"孕期食谱"——孕周 → 该阶段营养重点 → 围绕重点的食谱。与现有功能互补不重叠：每周指南的 `foods` 回答"吃哪些类型"，每日 `diet_tips` 回答"今天注意什么"，**食谱回答"具体吃哪道菜、怎么做"**。
> **定稿口径**（已拍板）：
> ① 菜品默认**非奶设计**（乳糖不耐友好，奶制品只出现在营养素知识条目中）；
> ② 主食**杂粮打底**（孕吐场景例外——精白软烂更好入口，指南口径也是碳水优先）；
> ③ 营养参考量只写有权威依据的（《中国居民膳食营养素参考摄入量 DRIs》《中国居民膳食指南（2022）》孕期口径），均标来源，版本差异见"待审定清单"；
> ④ 做法为通行家常做法整理，不虚构"独门食谱"；
> ⑤ 菜名后括注**跨段适用**范围，未标注的仅归本段。
> **审阅方式**：改文件或报菜名（"删 牡蛎豆腐汤"、"牛腩挪 mid2"）。
> 本稿先审**周段划分 + 营养重点 + 菜品收录 + 关键注意**；每道菜的完整食材表/分步做法在实施时补全（附录有 2 道完整样例看最终形态）。

## 一、周段 × 营养重点总表

孕周来自 `stores/health.js` 的 `todayWeekInfo`，落入 5 个周段之一（营养重点的切换点在 20 周和 36 周，早/中/晚三段表达不出来，40 周逐周又太重）：

| 周段 key | 范围 | 营养重点（按优先级） | 阶段说明一句话 |
|---|---|---|---|
| `early` | 1–12 周 | 叶酸 · 碘 · 足量碳水 | 神经管发育关键期；孕吐期以清淡适口、保证主食为先 |
| `mid1` | 13–19 周 | 钙 · 优质蛋白 · 维生素D | 骨骼发育启动、血容量上升，钙源以豆制品/鱼虾/芝麻酱为主（菜品默认非奶设计） |
| `mid2` | 20–27 周 | 铁 · DHA · 钙 | 贫血筛查窗口期，铁升为首位；胎儿脑发育加速 |
| `late1` | 28–35 周 | DHA · 铁 · 钙 | 脑发育高峰期 |
| `late2` | 36–40 周 | 控糖控体重 · 锌 · 铁 | 血糖/体重管理，为哺乳做储备 |

## 二、营养素条目（11 个）

页面顶部"本阶段营养重点"胶囊点开看到的内容就是这些条目；**页面主展示用下方"食物量速查口径"，mg/μg 数值与来源进详情折叠**（定稿口径）。

| key | 名称 | 为什么补（一句话） | 代表食物 | 参考量（DRIs 2023 核对定稿） |
|---|---|---|---|---|
| `folate` | 叶酸 | 预防神经管缺陷，孕早期最关键 | 深绿叶菜、豆类、强化谷物 | 600 μgDFE/d 全孕期（DRIs 2023 核对：与 2013 一致） |
| `iodine` | 碘 | 甲状腺激素合成，影响胎儿脑发育；孕期缺碘的后果比过量更明确 | **先看家里盐袋：配料表有"碘酸钾/碘化钾"才是加碘盐**；无碘盐家庭的碘全靠海产品（海带/紫菜/海鱼/贝类） | 230 μg/d（DRIs 2023 核对：与 2013 一致）；甲状腺疾病孕妇的碘摄入遵医嘱 |
| `carb` | 碳水（孕吐专题） | 孕吐期保证至少 130g/d 碳水防酮症 | 粥、面条、燕麦、烤面包片 | ≥130 g/d 孕吐期（膳食指南 2022） |
| `calcium` | 钙 | 胎儿骨骼牙齿发育，母体骨密度维护 | 奶、豆腐、绿叶菜、芝麻酱；**乳糖不耐路径**：无乳糖奶、酸奶/奶酪（发酵已降大半乳糖），或直接走非奶源（豆腐、绿叶菜、芝麻酱、带骨小鱼虾） | **孕期统一 800 mg/d（DRIs 2023，取消孕中晚期加量；UL 2000）**；膳食指南 2022 食物量口径仍按孕中晚 1000 设计（奶 500ml+豆制品），按高线吃同样安全；指南"增奶至500g"对不耐受者以酸奶/奶酪/豆制品折算替代 |
| `protein` | 优质蛋白 | 胎体生长 + 母体组织扩充 | 鱼禽蛋瘦肉、豆制品（食谱默认非奶） | 孕中期起奶增至 500g/d（+200g）；鱼禽蛋瘦肉孕中 +50g/d、孕晚再 +75g（合计较孕前多 125g）；每周 2~3 次深海鱼（膳食指南口径；乳糖不耐者奶以豆制品/蛋/瘦肉折算） |
| `vita` | 维生素A（植物源） | 胎儿发育必需；动物源过量有致畸上限，**植物胡萝卜素是安全通道**（体内按需转化） | 胡萝卜、南瓜、红薯、深绿叶菜 | 孕早 700 → 孕中晚 770 μgRAE/d（DRIs 2023 核对：维持）；植物源不受 UL（3000）约束 |
| `vitd` | 维生素D | 促钙吸收，食物来源少 | 日照、蛋黄、脂肪鱼 | 15 μg/d（600 IU，DRIs 2023 上调，原 10）；UL 50 μg/d |
| `iron` | 铁 | 血容量大增，缺铁性贫血影响母婴 | 红肉、动物肝血、配维C促吸收 | 孕早 18 → 孕中 24 → 孕晚 29 mg/d（DRIs 2023：孕早期随育龄女性基线 20→18 下调，中晚期维持） |
| `dha` | DHA | 胎儿大脑和视网膜发育主力 | 三文鱼、鲈鱼、鳕鱼（低汞鱼） | 孕中晚期 200 mg/d（中国营养学会孕产妇 DHA 共识 AI；2023 版 DRIs 沿用） |
| `zinc` | 锌 | 生长发育 + 免疫 + 分娩准备 | 牡蛎（全熟）、红肉、坚果 | 9.5 mg/d（DRIs 2023 核对：维持——孕中晚期较成年女 7.5 加 2） |
| `glucose` | 控糖控体重 | 孕晚期 GDM 风险管理、巨大儿预防 | 低GI主食替代、控含糖饮料甜点 | 非营养素，管理型条目：少精制糖、主食粗细搭配 |

### 食物量速查口径（页面主展示，定稿）

普通用户第一眼看到的说法；数值（上表）与来源进详情折叠。补充剂一律"遵医嘱"，本表只管食物。

| key | 页面主展示文案 |
|---|---|
| `folate` | 每天 400g 蔬菜、过半深绿叶菜 + 豆制品；孕前 3 个月起每天补叶酸 400μg（指南明确推荐） |
| `iodine` | 加碘盐家庭：常规炒菜 + 每周 1~2 次海带/紫菜即可（干紫菜 2.5g 或鲜海带 100g ≈ 110μg）；**无碘盐家庭**：海产（海带/紫菜/海鱼/贝类）每周 2~3 次打底——鱼池 11 种里海鱼占 7 种，按 DHA 口径每周 2~3 次鱼本身就在补碘；甲状腺疾病遵医嘱 |
| `carb` | 孕吐期每天至少 3 小碗粥/面类主食保底；吃不下时糖水/蜂蜜快速补糖，吐得严重进食少需就医 |
| `calcium` | 豆制品每餐有 + 绿叶菜（耐受者加奶 500ml）；虾皮、芝麻酱点缀 |
| `protein` | 每餐一掌心肉/鱼/蛋；孕中期起加量 |
| `vitd` | 每天晒 20~30 分钟太阳 + 每周 2~3 次鱼类 |
| `iron` | 孕中晚期每天加 20~50g 红肉 + 每周 1~2 次猪肝/鸭血（每次 20~50g）；配彩椒/番茄促吸收 |
| `dha` | 每周 2~3 次鱼、每次一掌心（本阶段鱼菜轮着做） |
| `zinc` | 红肉坚果日常已覆盖大半；牡蛎偶尔（务必全熟） |
| `vita` | 橙黄蔬菜（胡萝卜/南瓜/红薯）每周 3~4 次 + 每天绿叶菜 |
| `glucose` | 白米饭一半换杂粮；含糖饮料和甜点先砍掉 |

### 覆盖度核对（92 道定稿）

叶酸/碳水/钙/蛋白/铁/DHA/控糖每周段均 ≥3~4 道 primary（mid2 铁达 11 道、DHA 达 6 道、early 叶酸组 15 道、蛋白全程充裕）。结构补齐：**β-胡萝卜素通道**（胡萝卜/南瓜/红薯，新增 `vita` 营养素条目）、**深绿叶菜 13 种轮换**（菠菜/西兰花/芥兰/油麦菜/菜心/豆苗/苋菜/空心菜/地瓜叶/油菜/茼蒿/小白菜/芥菜——词典口径"深绿色叶菜每天都要有"，纯素叶菜统一标"适用全程"）、**汤品结构**（鸡汤系经审定不扩充；汤池：排骨/猪骨 4、豆腐系 7、鱼汤 3、牛尾/海带/时蔬/糖水若干，配"喝汤四条口径"）、**早餐结构**（粥 3+粉 2+馒头豆浆+三明治+玉米+蛋羹，固体主食 4 道、铁蛋白硬菜 3 道，配"早餐三角口径"；两道小米粥精简为南瓜版）。大白菜按浅色蔬菜诚实归类（冬季水分纤维+维C），不冒充深绿主力。三个例外——**碘**（菜品池：海带黄豆排骨汤+凉拌海带丝 2 道海带菜合计计频，加碘盐家庭每周1~2次/无碘盐 2~3 次；实操主力是盐——**先确认加碘盐与否再谈频率**，条目含判断入口与海产换算知识；海鱼池 7 种为隐性碘源）、**维D**（食物来源天然稀少，3 道+日晒口径）、**锌**（红肉坚果日常已覆盖大半，牡蛎 1 道主打）。轮换变体降为可选补充，不再必须。

### 鱼类选择口径（孕期低汞原则，与饮食安全词典同源）

- **推荐轮换（菜品池现有 11 种）**：鲈鱼、真鳕、三文鱼、黄花鱼、鲳鱼、鳜鱼、多宝鱼、带鱼、银鱼、龙利鱼、鲫鱼
- **澄清**：多宝鱼"避孕药"说法无据（鱼类喂避孕药无促生长作用，官方多次辟谣）；真实源头是 2006 年渔药残留事件（硝基呋喃/孔雀石绿），此后纳入重点监管——控制点是**正规渠道购买**
- **限量**：金枪鱼（水浸罐头少量，词典 caution 条目）、银鳕鱼（汞中等偏高，偶尔小块）
- **避免**：鲨鱼/剑鱼/旗鱼/大眼金枪（高汞）、一切生食鱼（刺身/寿司，孕期 avoid）
- **通行量**：每周 2~3 次、每次一掌心量；蒸煮优于煎炸（DHA 怕高温久炸）

### 喝汤口径（孕期四条，与鱼类选择口径同级）

1. **别久煲**：控制 1~1.5 小时内——久煮嘌呤高（孕期血尿酸本就易升）、叶酸等营养素怕热久煮；"煲三炖四"的老火传统孕期不适用
2. **吃汤渣**：汤里溶出的蛋白质不到肉里的一成，**汤渣才是主菜**，"喝汤弃渣"等于买水+盐
3. **少盐少油**：汤后放盐、撇浮油；控糖控体重期尤其
4. **药材红线**：当归、川芎、红花、益母草等活血药材汤底孕期 **avoid**（四物汤、当归鸡汤孕期不喝；挂词典"自行服用中草药（含活血类）"条目）

### 早餐结构口径（孕期）

- **三角结构**：主食（粥/粉/馒头/玉米）+ 蛋白（蛋/豆浆/粥里加肉/早茶点心）+ 有条件配点果蔬——齐两角也算合格早餐
- **孕吐期例外**：能吃下什么吃什么，碳水优先、少量多次（130g/d 保底口径）
- **外食早餐**：粉店选汤粉少喝汤（钠集中）、早茶适量（虾饺烧卖钠+肥馅）、油条炸物不吃（词典油炸类口径）

### 带饭口径（上班族午餐）

**两条路径**：
1. **晚备早做（推荐）**：前一晚把菜洗好切好、肉腌好（密封冷藏），早上 15 分钟现炒装盒——当天做的菜中午吃，**绿叶菜也没问题**；电饭煲预约杂粮饭/粥，早上同步出锅
2. **前一晚做好（适合炖/卤/蒸）**：这类菜隔夜更入味，遵守下面安全三条；隔夜路径的配菜选瓜/茎/菌菇/根茎类（凉拌菜、大叶绿叶菜不走此路径）

**安全三条（孕期特严）**：
1. **冷透存、滚烫吃**：做好的菜 **1 小时内急冷进冰箱**（≤4℃），通勤冰袋、到公司即冷藏，吃前**彻底加热到滚烫**——孕妇是李斯特菌高危人群，铁律
2. **备菜卫生**：生熟分开、备好的菜密封冷藏（晚备早做路径同样适用）；早上炒好后尽快装盒降温
3. **鱼虾海鲜不带**（久置风险+复热腥）：鱼晚餐现做（清蒸 8 分钟正好下班做）；汤用焖烧杯（装前热水烫杯）

**复热适口分级**：炖/焖/蒸/卤 > 快炒 > 凉拌/汤面（凉拌/汤面两路径都不带）

**带饭十二选**（隔夜路径适用；"晚备早做"路径下全部快炒菜皆可带）：

| 类别 | 菜品 |
|---|---|
| 荤主菜 ×6 | 杂粮饭卤牛肉、番茄炖牛腩、豉汁蒸排骨、客家酿豆腐、黄豆焖鸡腿、生焗梅花肉（热透无血水） |
| 半荤配菜 ×4 | 黑胡椒牛肉杏鲍菇、花菇炒牛肉、香干炒芹菜、青瓜炒牛肉 |
| 主食 ×2 | 杂粮饭、红豆糙米饭 |
| 汤（焖烧杯）×2 | 杂菌菇豆腐汤、番茄土豆牛尾汤（撇油后装） |

**周末现做**：周六周日在家现做现吃，不受带饭限制——把工作日受限的"现吃菜"安排到周末：清蒸鱼/白灼虾（鱼虾现做 8~10 分钟）、绿叶快炒、凉拌菜、汤面；一周结构 = 工作日带饭（晚备早做 + 炖卤蒸隔夜）+ 周末鲜货现做。

用户审定菜单 25 道全部可食（零 avoid），其中 4 道高钠注意（酸菜牛肉煲、酸咸菜炒梅花肉、南乳煎焗排骨、沙茶炒猪雪花——腌制品/发酵酱/复合酱，少量配不作常态）；"生焗/煎焗"类已注明烹法定义与全熟要求。

### 今日三餐（第一版 · 无状态确定性轮换）

- **入口**：食谱页阶段卡下"今日三餐"卡——早/午/晚(+加餐)四行 + 今日主打营养标签
- **确定性轮换**：按 dayOfYear+周段计算，同一天任何时刻打开组合相同，次日自然换；"换一组"按钮仅内存偏移（不落盘、次日恢复默认）
- **按星期切池**：周一~五午餐从**带饭友好池**选（晚备早做+炖卤蒸），周六日从**现做池**选（含鱼虾鲜货）——对齐"带饭口径"的一周结构
- **营养覆盖**：午餐优先命中段第一优先营养（如 mid2=铁）、晚餐第二优先（DHA）、早餐碳水/蛋白打底；池空回退全段池
- **频率受限菜不进轮换池**（自动推荐不推荐"该少吃"的菜）：猪肝×2、海带×2、腌制高钠×4（酸菜牛肉煲/酸咸菜炒梅花肉/南乳煎焗排骨/沙茶炒猪雪花）、早茶拼盘——这些菜页面照常可手动浏览，只是不自动排进三餐
- **披露**：卡片底部标"今日主打：铁 · DHA"+ 工作日/周末模式标签

## 四、与饮食安全词典的交叉引用

菜品的 `cautions` 引用 `food-safety.json` 词条 id，两个功能互相背书（实施时对齐真实 id）：

- 猪肝菠菜汤 → 词典"动物肝脏"（caution：每周≤1~2次）
- 牡蛎豆腐汤 → 词典生食海鲜类条目（彻底煮熟前提）
- 清蒸鲈鱼 / 香煎鳕鱼 / 蒜蓉豉汁焗鲈鱼 → 词典鱼类条目（低汞选择、避免大型掠食鱼）
- 彩椒炒牛肉 → 词典"五分熟牛排"（avoid）反向印证"全熟"要求；黑胡椒牛肉杏鲍菇 / 鹿茸菇炒牛肉 / 花菇炒牛肉 / 油麦菜炒牛肉 / 青瓜炒牛肉 / 酸菜牛肉煲 同口径
- 核桃虾仁炒西芹 / 花菜炒大虾 / 甜豆炒鱿鱼虾梅花肉 → 词典"全熟虾/全熟螃蟹"澄清条目；鱿鱼同"彻底煮熟"口径
- 豆浆燕麦糊 → 词典"豆浆（彻底煮沸）"
- 上汤豆苗 → 词典"皮蛋（松花蛋）"（avoid）——做法规避不放皮蛋，改清汤/瘦肉汤底
- 芥末炒芥兰 → 词典"辣椒（熟制、肠胃耐受）"澄清口径（无禁忌依据）
