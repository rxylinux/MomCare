# B2a 实施交接：持久同步与真实健康档案页面

基线 `b97b407`。用户已明确部署统一延后，不再以缺 AppID/env 阻塞实现。先阅读 `docs/DELIVERY_STATUS.md`、PRD、DESIGN 与实施规划。ZCode 编码，Codex review；本轮只交付 B2a 并冻结，不自行提交/推送/部署。

## 本轮范围

完成能被后续模块复用的最小同步协议，并贯通**现有首页健康记录、孕期资料设置、私人心情/备注与趋势页面**。B1 家庭页保留诊断和配置入口，但不能是唯一能访问正式数据的页面。产检/待产包/报告完整接入是 B2b，共同任务/分享需要是 C，旧数据迁移/导出恢复是 B3；保持接口可扩展，不建设通用框架。

## 必须保持的边界

1. 固定两成员与服务端可信身份不变；首页视角不参与鉴权。冷启动先确认身份再恢复成员缓存，运行中同一已验证身份可离线写待办。旧 HTTP、旧无归属正式键仍关闭；独立演示不写新云数据。
2. 正式健康数字与孕期档案家庭共享；记录对象为妈妈，操作者由服务端生成。心情、症状描述、日常备注默认仅本人可见，不能把旧 `saveRecord` 的整份对象塞进共享 payload.note；明确分享另由 C 实现。列表、趋势、错误、冲突均不得携带另一成员私人原文。
3. 一份孕期档案以固定文档 ID + revision/原子操作保证两端首次创建不重复。schemaVersion 不支持时明确拒绝，不能丢未知字段后覆盖。
4. 不恢复自动样例、不制造 token、不要求先开演示进入正式首页。缺配置/H5 显示不可用；只在可用且确认身份后进入正式流程。实际退出、身份切换、回前台确认失败均清理响应和 store 内存的可见数据，原成员未同步内容仍持久保留。
5. B1 家庭页与 B2 正式页不能成为两套互不相通的健康/私人数据。若新增集合或函数，明确将 B1 业务入口切到同一权威源，或将家庭页收敛为身份/配置诊断并关闭旧业务写入。保留 B1 历史契约测试时据实说明，不能让原端点绕过 B2 的删除/版本保护。单字段表单提交须保留其他字段；空值/删除语义明确，不用 truthy 判定吞掉胎动 0 或空文本清除。

## 服务端与同步约定

- 云记录包含 schemaVersion、revision、updatedAt、updatedBy、明确 deleted 标记；时间由服务端生成。日期按 Asia/Shanghai 日号；实际时刻存时间戳。
- 变更必须传严格整数 expectedRevision 和稳定 operationId。操作 ID 按家庭/成员/操作范围隔离、绑定规范化内容；revision 变更与幂等结果在同一事务内完成。重放不能把后来已删除或撤回的数据正文重新发给其他成员。
- 分页具有稳定唯一排序与游标，测试超过平台单页上限的数据。只有全部页成功才推进完整同步时间；分页失败保留旧快照与待办，不按缺失项推断删除。合并按 revision，低版本不能覆盖高版本；tombstone 阻止旧编辑复活。
- 小规模按需同步：启动/回前台/手动刷新/提交成功后触发。并发刷新/重试只运行单个实际发送循环，避免重复计时器和重复网络；不引入常驻连接。

## 持久 outbox 和冲突

- 在发网络前把请求快照、稳定 operationId、expectedRevision、实体 ID 与本地状态写入成员隔离 outbox。落盘失败不发请求、不提示已保存。确认成功后再持久化结果并移除对应待办；清除落盘失败保留可幂等重放状态，重启不丢操作。
- 网络超时或响应丢失重试**原 ID + 原内容**；同实体的后续编辑排队，不能改写已发送 operationId 的 payload。若合并尚未发送项，明确限制并测试。私人和共享保存分开追踪，局部成功不清掉另一半输入。
- 版本冲突保留本地输入，显示云端版本与本地修改；选择采用云端或确认重提。重提使用最新 revision 和新 operationId；删除冲突不得自动复活。业务拒绝与网络失败区分，身份拒绝立即锁定。
- 所有异步回调绑定开始时的 epoch 和成员，在改变 UI/cache/outbox 之前检查；确认在途不得按旧身份读写新状态。成员切换不会把迟到失败分支写进新命名空间。
- 退出提示未同步内容仍保留在本人账户，保留返回处理机会；不得为下一身份加载，也不默认丢弃。

## 页面验收

复用现有 Pinia/表单并接正式服务；可拆出独立家庭 store。展示当前成员、真实待同步/冲突/最近完整同步时间；不把 optimistic 本地值标为云端成功。体重、血压、胎动数字和孕期资料必须通过真实处理器流入 outbox/云函数；私人输入进入独立私人路径。趋势从成员已确认的数据源读取，不能回读旧隔离键。

本阶段新增/调整逻辑要有合成数据的实际生产路径测试，不能只抽取重写版函数。至少包括：两端首次建档竞争；分页超过单页且中途失败；响应丢失后重启重放；连续编辑同记录；部分私人/共享成功；删除和迟到编辑；明确拒绝与临时离线；成员切换时挂起读写；落盘失败/确认后清队失败；现有表单/趋势实际接入；零旧 HTTP。
