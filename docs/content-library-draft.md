# 孕期内容库 v2 起草稿（审阅版）

> **用途**：替换现役两处内容——①首页"今日提醒"普通日子的兜底文案（原 84 条重复库）；②每天 9 点推送的"平日提示行"（现役 v1 小词库 11 条）。
> **规则**（已定）：结合孕周阶段变化 + 营养按孕周轮换 + 水果写当季具体果名（适量 200~350g/天，不催多吃）。
> **边界**：只写常识性孕育知识与生活建议，不做诊断、不写"危险"类表述；一切以产检医生意见为准。
> **审阅方式**：直接改本文件，或把要改的条目编号发我（例："14-3 改成 xxx"、"删 39-4"）。
