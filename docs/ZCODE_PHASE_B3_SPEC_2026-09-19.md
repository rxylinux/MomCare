# B3 实施交接：旧数据确认、完整备份和隔离恢复

状态：Codex 方案准备；必须在 B2b2 验收提交后开始。具体报告/附件接口以 B2b2 最终冻结实现为准。本轮仅合成数据开发与验收，不接触真实旧数据，不部署，不替用户确认来源。

## 当前入口与旧数据

`utils/storage.js` 已隔离 `YUNTU_HEALTH_DATA`、`YUNTU_REPORTS_DATA`，保留 `MOMCARE_BACKUP_HEALTH_*` / `MOMCARE_BACKUP_REPORTS_*` 原始备份；旧待产包键为 `hospital_bag_items`。`pages/profile/privacy.vue` 当前只列出本机备份数量，不等于具备完整导出/恢复。正式功能从“我的/隐私与数据”进入，提供来源预览、导出和恢复三个清晰操作；现有旧确认/清除入口需避免误导为 CloudBase 的新迁移流程。

源扫描只读取白名单业务键和对应附件，不遍历/导出登录 token、OpenID、API 密钥或整份存储。原始来源备份只留本机，解析并经预览确认的业务字段才可迁入。读取异常或未知格式显示失败，不当成空集合；演示与未确认数据单独列出。

## 迁移协议

1. 预览列出来源、记录数、共享字段/私人字段拆分、日期/类型错误和缺失附件。用户明确选择哪些是真实旧记录，私人作者只能确认当前本人；不能代另一成员确认。无法判断的原始数据留在隔离区。
2. 确认绑定当前身份、源内容摘要、字段选择和迁移批次；内容变化、身份变化、确认失效均重新预览。先持久保存迁移清单，再逐实体执行。批次含稳定源 ID、目标 ID、操作 ID、原/目标版本、附件映射和状态。
3. 已成功条目在重启/丢响应后用原 ID 重放；失败/冲突有继续处理入口，不能整批重建。迁入不覆盖较新或已删除的云记录。清单读写失败停止发送，源原件不删除。
4. 附件来源必须是授权可读的本机实体或现有受控云引用，不提供任意 URL 的云端下载代理。未找到原件不得伪造“完整迁入”。

## 完整导出

建立版本化清单（formatVersion=1）：生成时间、范围、各领域记录数、稳定记录 ID/revision/墓碑、逐附件相对路径/内容类型/大小/SHA256 和报告→附件顺序映射。共享数据可导出；私人范围只能包含当前本人，服务端重新授权；不信任客户端传 owner/member 来扩大范围。

附件必须包含实际字节，不能只保存 fileID 或临时 URL。逐文件处理，有数量/总量/单文件上限，不把全量原件塞进同步 KV 或一个无上限 JSON。生成前列出将导出的范围和估算大小；缺附件/超限/网络失败显示明确不完整状态。只有清单、记录和全部附件校验成功才标完整。

导出过程中其他端修改时，采用可解释的版本清单/受控重试；记录实际取得的各实体版本，不宣称未经实现的原子快照。删除后的下载/幂等响应仍需重新授权与墓碑校验。用户主动创建的离线备份不能承诺远程撤回。

## 恢复与平台实现选择

先校验格式版本、摘要、大小/数量、路径规范、重复路径、重复 ID、附件映射和领域 schema，再展示预览；拒绝路径穿越、绝对路径、缺文件、损坏和未知版本。备份中带来的 family/owner/OpenID、云 fileID 不构成授权；附件重新登记，调用者身份由 CloudBase 确认。

恢复验收写入独立 restoreBatch 命名空间或隔离集合，不改实时家庭档案。隔离记录和文件仍由当前家庭鉴权，不可被实时首页/任务/统计混读。提供打开恢复报告和逐项校验结果的实际页面。合并到当前档案如需要，必须是另一个有冲突预览的明确操作，不作为“恢复验证”的隐式副作用。

ZCode 开始实现时先提交包格式、微信小程序实际文件 API/库、H5 适配方式及容量限制的选择，并核对当时官方接口或锁定 SDK 源码。H5 能下载不是小程序已能导出；不能用浏览器专用 API 充当小程序实现。不要在此阶段为了验证安装真环境或申请外部权限。

## 本轮验收

- 合成旧健康/报告/待产包预览→本人来源确认→中途失败→重启继续→重复执行；原始字节不变，目标不重复，源改变须重新确认。
- 实际 UI→服务→handler 的导出、导入处理器；双方身份及私人 canary、第三身份拒绝、身份切换迟到回调、明确演示隔离。
- 导出包含多张有效合成图片，重新加载包到隔离恢复区，逐文件比对 SHA256，并实际解码/打开恢复图片。缺失/损坏/版本不支持/超限均明确失败，不误标完整。
- 路径穿越、重复文件、错误映射、跨家庭/私人 owner 伪造、云引用注入、删除与导出竞态、待同步版本冲突和磁盘失败。
- 保留 B1/B2a/B2b1/B2b2 相关回归，冻结后构建双端并列出全部改动哈希。真实原件迁移、真机文件交互、真实备份恢复仍列最终部署待办。
