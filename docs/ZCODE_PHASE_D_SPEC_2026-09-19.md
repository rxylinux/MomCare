# D 实施交接：本地发布准备与最终部署清单

状态：Codex 方案准备，C 验收提交后启动。本阶段完成代码/构建和交付材料；真实环境配置、发布及双手机验收仍留到全部本地任务通过后统一处理。

## 当前已核对的待办

- `package.json` 的默认 deploy 指向旧 Cloudflare H5，不得运行。改成明确的历史预览命令名称或移除误导入口；不销毁旧远端资源，不把 CloudBase 配置悄悄回退到旧服务。
- `manifest.json` 当前小程序 AppID 为 touristappid；它是占位，不能据此说已可发布。保留缺配置时的明确关闭状态，提供发布前校验脚本和环境变量/配置清单，不把真实密钥写入客户端。
- 本轮观察的未最终优化 mp-weixin 产物约12MB、static 约9.4MB。源文件 `static/momcare.mobileconfig` 为5,441,372字节，`static/logo.png` 为4,079,741字节；这些是当前测量，不是发布包验收结果。先检查引用，排除小程序不需要的 iOS/H5 安装资源并选择适用已有资产。最终重新测量主包/分包，不能把总目录大小当开发者工具实际上传包体。
- 核对 `stores` 中静态知识/日历内容加载路径在小程序产物中真实可读，不能依赖 H5 fetch 或服务器根绝对路径。缺内容如实显示，不造假来源或医学认证。

## 本地发布前检查

逐项列出实际页面、入口与关闭状态：身份、健康、产检、待产包、原件报告、迁移/完整备份/隔离恢复、两种首页、分享与任务。清理旧密码登录/假同步/会员额度/无效计算器等误导入口，不能仅隐藏一个首页按钮而其他深链仍进入旧流程。确认退出、冷启动、演示隔离、原件恢复等已有行为不回退。

特别复核“我的”页全部摘要：B2b1只负责产检/待产包，其他孕期字段、体重/血压/胎动统计、报告数与AI额度仍需以届时真实权威来源逐项核对；不得因页面有 familyStore import 就判定所有卡片已接入。结合 C 的首页调整修齐剩余来源与误导文案，报告卡等待 B2b2 实际模型，不用旧本地空状态伪装云端无数据。

核对敏感操作文案、私人/共享标记、暂无数据、失败/待同步/冲突、AI未启用；无 OCR/DeepSeek 真实成功证据，继续明确未启用，基本记录和原件阅读不依赖它。无依据的“医生认证”“日正常”等医学保证按 PRD 清理或交内容审核，不能凭开发测试宣称医学正确。

保留独立构建流程和云函数装配锁定依赖；检查最终产物没有服务端密钥、旧 HTTP 回退、调试身份注入入口的用户可访问开关。测试替身只能由本地测试主动注入，默认生产路径仍依赖真实身份。构建退出成功只代表本地构建，不代表平台审核或真机已验收。

ZCode 提交每项需求的覆盖矩阵、所有阶段提交 SHA、完整回归及双端构建、最终文件哈希/资源测量和恢复样例证据。Codex 复验后将 DELIVERY_STATUS 汇总为“已实现/已本地验证/待真机/未启用”，不把待部署的项目勾成已完成。

## 全部本地通过后才处理

使用当前官方平台文档核对包体/分包、权限、云资源、规则、接口及费用。此时再收集真实 AppID、CloudBase 环境、两个成员白名单、体验资格与供应商配置；逐步执行部署和安全规则验证，通过后才开客户端上传。

最终验收覆盖两台手机及第三身份拒绝：相机/相册、文件持久化/备份导入导出、冷启动离线、切后台、Wi-Fi/移动网络、上海跨日、两个视角和私人 canary、上传中断/丢响应、任务/分享撤回、真实SDK分页和事务。真实旧数据先确认来源再迁移；真实完整备份在隔离区恢复并打开附件。AI另验成功/失败/超时和第三方处理说明，不做真实医学诊断测试数据分享。

未通过项保持关闭或明确限制，记录原因和下一步。最终发布/真机结论以实际平台与手机证据为准，不以模拟器、单元测试或 H5 截图替代。
