## 权威模型与操作

- 一条报告有稳定 ID、schemaVersion、revision、deleted、家庭、上传者、日期、类型、归档状态、用户备注及有序附件引用。附件用已登记的稳定 fileId；临时 URL 仅作当前预览。报告字段白名单和长度、最多附件数/大小需明示。标注调用者与文件上传者的不同含义。
- 选取一组原件后先保存本地实体副本和成员隔离的持久批次清单，再发网络请求。新图片用新 uploadId；重试沿用原 ID/内容与图片顺序。文件落盘失败不能开始上传，清单落盘失败不能留下虚假“已排队”。不默认低质量压缩替代原件。
- 一个批次各附件独立推进到已登记；报告创建用稳定操作 ID。部分成功只重试未完成项，丢失登记/报告响应可安全重放。未全部完成时明确显示状态；不得把半成品当完整报告或让成功附件消失。
- 报告编辑/批量归档逐实体捕获原 revision；部分成功、冲突、失败分开反馈。改分类只改对应字段，不覆盖日期、备注和附件。列表稳定分页含墓碑，日期相同用稳定 ID 区分；只有完整读取成功才更新时间。
- 本地、服务端都校验引用属于当前家庭并已登记可用，不能接受客户端任意 fileID/URL。下载、分析入口每次重新鉴权及确认报告未删除；历史幂等响应不能绕过删除。

## 删除与清理的边界

先原子记录报告墓碑和引用变更，阻止旧写入复活；再通过可重试清理任务删除无其他有效引用的文件。清理中的文件不可被新报告重新引用，清理与登记/引用需有共同的并发保护。一个报告删除后，其他仍引用同文件的报告继续可读。

暂存或孤立文件只在保留期已过、没有活跃登记任务、没有正式引用时回收。服务端验证条件，不由客户端自行指定任意云路径删除。清理失败保留状态供重试，禁止“失败即完成”。本阶段只用隔离合成 SDK 数据验证；不清理真实云文件，不配置定时云任务。

## 会话、迁移与 AI

- 未确认、锁定、退出、切成员时清空当前可见报告/预览，保留本人持久上传批次；迟到回调不能写入新成员状态。冷启动先真实身份确认，再显示缓存或重试。
- 演示独立存储和文件状态；旧正式报告原件保留给 B3 来源确认，本阶段不自动读入正式档案、上传或清空。禁止回退旧 Cloudflare HTTP。
- 缺平台/配置、上传开关关闭要能浏览说明和退出，不假成功。AI 按现有配置保持明确未启用，支持手动分类与阅读原件。无 OCR/模型成功证据不得显示“分析完成”“全部正常”；不得为了演示制造诊断。

## 冻结前必交证据

1. 真实 UploadSheet 处理器 → 持久副本/队列 → 真实 mc-files/报告 handler → 列表/详情/分类/批量入口；一份多图报告的原件顺序、大小/摘要与预览均一致。
2. 部分上传失败、登记/创建响应丢失、应用重启恢复、选择取消、持久文件缺失、空间/存储失败及显式重选；成功项不重复上传/建报告。
3. 成员切换期间挂起上传、服务端身份拒绝、报告删除与读取/登记/重放竞态、共享文件引用保护、清理失败恢复与活跃任务不被清理。
4. 大于默认页长的列表及同日记录、分页中途失败、编辑中刷新/冲突、null 与空字段；旧报告数据原始字节不变，零旧 HTTP。
5. 单一页面 bundle 中的真实 session/config/adapter/store，模板对非空和空数据均能消费，不只做导入/关键词测试。B1/B2a/B2b1 相关回归、双端构建、未绑定变量检查与全变更 SHA256。
