# MomCare 微信云开发部署与迁移方案

日期：2026-09-19。状态：用户已确定选型，待实现及部署。本次仅更新方案，没有创建云资源、修改业务代码或验证线上服务。

同日复审补充：明确离线身份边界、暂存文件转正式原件、分页完整性、AI 超时恢复及含附件备份。以下是交付约束，不要求为两个用户建设复杂平台。

ZCode 负责实现、迁移、构建与联调；Codex 负责方案和代码 review。产品范围及私人数据边界以 [PRD](../PRD.md) 为准，开发顺序沿用[实施规划](../DEVELOPMENT_PLAN_6_FEATURES.md)。

## 1. 确定的架构

微信小程序通过 `wx.cloud` 原生能力接入与真实 AppID 关联的微信云开发环境；首版使用文档数据库模式、云函数和云存储。继续使用现有 UniApp / Vue / Pinia，微信相关调用封装在平台适配层。

| 内容 | 存放位置与职责 |
| --- | --- |
| 孕期资料、健康数字、产检、任务、待产包、报告元数据 | CloudBase 文档数据库，共享记录由两个成员访问 |
| 心情、私人备注等 | 独立私人集合，仅本人经鉴权接口读写 |
| 报告图片原件 | CloudBase 云存储；数据库保存稳定 fileID 与所属报告，不持久化临时访问 URL |
| 离线记录和最近数据 | 手机本地缓存，绑定已确认成员；待同步项持久保留 |
| 身份、权限、同步校验、AI 编排 | CloudBase 云函数 |
| DeepSeek / OCR 密钥 | 云端环境变量或密钥管理，客户端不持有 |

不购买独立服务器、不维护系统或 Nginx；不为首版增加容器或独立 HTTP 网关。原生云调用路线不要求自建 API 域名，但不代表免除小程序平台手续；若后续引入普通外部请求，单独核对对应域名配置。H5 仅保留开发预览能力，不复用游客身份访问真实数据；正式 H5 身份接入另行设计。

## 2. 用户需要准备什么

1. 真实微信小程序账号与 AppID，按当前平台要求完成主体信息及使用所需手续。
2. 开通与该 AppID 关联的微信云开发环境，记录环境 ID；环境 ID 可用于客户端配置，不是密钥。
3. 添加本人和妻子为体验成员，准备两台手机验证。体验成员资格和服务端两人白名单分别配置，不能互相替代。
4. 准备 DeepSeek 账号、余额和 API Key；OCR 服务商由 ZCode 在实施时确认实际可用接口和费用。没有配置时明确关闭 AI，不阻塞记录与原件功能。
5. 如旧手机或旧云端已有记录，保留原数据并安排备份。尚未核实是否存在旧云端真实数据，不假定为空。

密码和 API Key 直接填写云端配置，不通过聊天或文档收集。套餐、额度、资源地域和费用以开通时控制台为准；先使用满足需求的最小规格，设置费用提醒，不承诺永久免费。真实数据进入正式环境，联调使用隔离环境；不能在正式档案中灌入测试记录。

## 3. 身份和访问权限

- 客户端初始化明确的环境 ID，业务调用经 `wx.cloud.callFunction`；云函数从可信微信上下文获取 OpenID，并验证来源 AppID、固定家庭与成员映射，不信任客户端声明的身份。
- 通过受控的身份查询获取各自 OpenID，由管理员核对后加入两成员配置。该查询最多返回调用者自身身份，不返回家庭数据；不能采用“最先登录的两个人自动成为成员”。所有正式业务函数遇到缺失或未知身份均拒绝。
- 结构化业务数据库默认拒绝客户端直接读写，统一经云函数授权和参数校验；私人集合逐条核对 ownerId。服务端 SDK 权限较高，不能认为数据库安全规则会自动替云函数过滤数据。
- 文件权限必须与业务权限一起部署：禁止公共读写，直接上传只允许白名单成员写入本人暂存目录，不能覆盖已有正式原件。客户端直传所需的具体规则及其拒绝用例由 ZCode 随实现交付。
- 云函数确认暂存文件的实际归属、路径、类型和大小后登记报告；不得仅凭客户端提供的 fileID 挂入档案。查看、删除、生成临时访问地址前先验证成员和报告归属，服务端不能接受任意 fileID 作为下载代理。
- 如使用临时下载地址，按有效期短暂使用，不写入日志、公开页面或永久数据。临时地址是可转发的访问凭证，移除成员不保证已签发地址立即失效；交付时记录实际有效期并说明边界。
- 退出、身份变化、共享撤回及导出遵守 PRD；日志只保留定位所需的请求 ID、状态和错误类别，不记录密钥、整份报告或私人原文。

### 3.1 首版需要说清楚的身份边界

- “仅本人可见”是小程序及业务接口的访问承诺，不是端到端加密。持有云控制台或服务端管理权限的人可以读取后台数据；首次私人记录说明中明确这一点。首版不增加自行实现的加密系统。
- 本地缓存按环境 ID、AppID、memberId、数据版本隔离，但缓存键不是身份验证。首版冷启动需要联网确认身份后再展示持久缓存；同一已验证运行会话断网时可以继续查看和暂存。回前台恢复联网时重新确认身份，被明确拒绝立即锁定数据并停止同步。
- 冷启动断网时保留待同步内容，显示“联网确认身份后恢复记录”，不自动读出上一会话的私人数据。换微信账号、成员被移除、主动退出分别验证；不能用“上次登录过”替代本次身份确认。当前会话离线期间不能保证即时得知云端成员撤销。
- 小程序主体、AppID 和环境首次选定后尽量保持稳定。变更时重新获取并核对 OpenID 映射；不能假定其他 AppID 下的 OpenID 可以直接沿用。

## 4. ZCode 迁移任务

按实施规划阶段 A → B → C → D 推进。本节补充阶段 B 的具体要求，不要求重写全部页面。

1. **建立云接入层。** 用真实 AppID / 环境 ID 替换游客配置，接入原生云调用；用可信成员状态替代 guest_mock_token，替换旧 HTTP/JWT 业务路径。错误原样进入可处理的失败状态，禁止离线伪成功。
2. **接入共享存储。** 按规划实体建立集合和必要索引，家庭及孕期只有一份。服务端执行 revision 检查、操作 ID 去重和冲突返回；同一操作并发重试也不能多写一条。具体原子更新/事务方式在实现中提供证据。
3. **接入文件。** 使用云存储上传和稳定 fileID；上传成功且元数据登记成功才显示报告已同步。上传后登记失败可安全重试，遗留暂存文件可回收，不能误删已登记原件。删除与重试保留一致的可恢复状态。
4. **接入可选 AI。** 云函数按已授权 reportId 获取原件，经 OCR 提取后调用 DeepSeek；提供未启用、处理中、完成和失败状态。模型、接口、响应结构和超时实施时确认；空结果、非预期响应或失败不能显示完成。长耗时任务使用可恢复任务状态与查询，不能要求页面一直保持打开。
5. **约束费用。** 服务端限制两人共用的 AI 次数、并发和重试；一次成功结果只记一次本地业务用量。供应商超时后是否已计费可能不确定，先查任务状态，避免盲目重复调用；“失败不扣成功次数”不等于外部供应商不收费。
6. **迁移旧数据。** 先备份，再确认来源及演示数据；未确认所属人的缓存不得自动合并。将旧文件实际复制入云存储，保留迁移映射用于去重；核对记录数量、字段、附件可打开和私人边界，并在隔离环境验证恢复。
7. **切换单一数据源。** 切换前暂停旧端写入并完成最终核对；正式版本只写 CloudBase，失败时本地暂存并提示，不自动回落 Cloudflare。旧资源暂留备份，不自动销毁。若需回退，先保存切换后新增数据再制定恢复步骤，不能简单换回旧地址造成数据丢失。

报告内容发送到 OCR / DeepSeek 属于第三方处理；上传说明与发起 AI 解读的说明分别呈现，私人笔记不自动进入 AI 上下文。未启用 AI 时两人仍能记录、上传、查看原件及准备问题。

### 4.1 文件生命周期与报告清晰度

- **暂存 → 校验 → 正式原件 → 登记完成**：客户端只能直传本人暂存目录。服务端将内容复制到客户端不可写的正式目录，校验正式副本后再发布报告元数据；不能只在数据库把暂存路径改名为“正式”。正式目录的上传、覆盖和删除均由云函数管理。
- 同一上传使用固定 uploadId 和服务端生成的正式路径；重复确认返回同一报告。正式文件成功而登记失败时可续办，不留出“清理器误删仍在登记中的文件”的窗口；清理只处理超过保留期、没有有效处理任务且无正式引用的暂存或孤立文件。
- 离线待上传图片须复制到可持久恢复的本地文件位置，不能只记拍照/压缩返回的临时路径。保存失败或空间不足保留明确错误，不能提示“已暂存”。云端确认成功后才按缓存策略回收本地副本。
- 原件须可放大辨认日期、单位、小数点和参考范围，不沿用当前固定 `quality: 20` 的压缩作为默认验收标准。缩略图和用于留档的可读原件分开；上传大小、格式及像素限制由客户端提示并由服务端复核。
- 删除先把报告标为已删除并禁止新下载/AI 调用，再重试清理实体文件；标记保留以阻止旧端把数据重新传回。文件与数据库不属于同一事务，必须测试每一步中断后的恢复。

### 4.2 同步不能只验收少量记录

- 查询使用稳定排序和明确分页；单次 get 的结果不得当作完整档案。全部页面成功后才更新“完整同步时间”；中途失败保留原缓存和待同步项，不能把列表缺失项当成已删除。
- 删除与撤回依据明确标记处理；首版数据量小，保留不含敏感正文的删除标记，不急于做过期清理。分页期间并发修改时允许重拉并按 revision 合并，旧版本不得覆盖新版本；恢复备份另用受控导入流程。
- 操作 ID 的去重范围包括成员和业务操作，并绑定相同请求内容；同 ID 不同内容拒绝。同一修改的重试保持 ID 不变，用户解决冲突后以最新 revision 发起新的操作 ID。
- 记录写入、revision 更新和去重结果须原子提交。先查再插不是并发保护；接下同一需求、首次建档和待产包生成任务也必须有唯一性约束或等效原子保障。
- 共享需要撤回时，对方尚未同步的编辑/接单不能使原文复活；冲突界面也不能重新把已撤回正文发给对方。

### 4.3 AI 任务的最低可靠约定

- 以 reportId、原件版本和分析配置标识同一次分析；两个人同时点击只领取一个执行任务。记录任务 ID、状态、执行期限、供应商请求 ID（若有）和结果版本。报告删除或原件变更后，旧任务结果不能写回新版本。
- 不把“返回 taskId 后启动一个未等待的 Promise”当作可靠后台执行。首版可采用受控执行调用等待结果、客户端随时查询持久状态的方式；若使用异步触发，需验证所选平台机制的实际触发及补偿行为，不先引入额外队列产品。
- 客户端等待结束、云函数终止、供应商请求失败是三种情况。任务超过执行期限时显示“结果待确认”，先查已有结果；供应商不支持查询/幂等时，明确说明重试可能再次计费，由用户发起，禁止无限自动重试。晚到结果和新的尝试按执行版本仲裁，避免重复入账或覆盖。
- OCR 文本按外部数据处理，不执行报告文字中的指令；AI 只返回待展示的数据结构，不开放删除记录、调用任意网址或自动生成医疗行动的工具。保留来源图，识别不清允许用户核对，AI 不改写原始健康记录。

### 4.4 备份、停服与版本更新

- 数据库备份不能替代报告文件备份。可恢复导出需包含 schemaVersion、记录、附件实体及文件映射/校验信息；只有 fileID 或临时 URL 不算完整备份。应用内导出继续遵守“共享数据 + 可选本人私人记录”，不开放全员私人数据导出。
- 首版提供手动导出及恢复说明；上线前、数据迁移或破坏性升级前保留独立副本。使用平台自动备份前核实当前环境支持范围及保留期，不承诺固定额度或永久保存。包含真实报告的备份由用户妥善保存在受控位置，不进 Git。
- 费用提醒并非自动硬限额。云服务与 OCR/DeepSeek 分别检查余额、用量和服务状态；AI 达到业务预算时只停 AI。云环境不可用时明确同步失败，保留本地待同步内容，不能承诺停服期间跨设备同步。
- 数据带 schemaVersion，部署先兼容旧客户端，再发布新体验版；两台手机可能暂时运行不同版本。若旧版不能安全提交则显示升级提示并保留草稿，禁止默默丢字段或覆盖新数据。

### 4.5 保持两人项目的实现规模

先完成小范围接入验证：真实身份、双向一条记录、一次文件上传/查看、非成员拒绝。通过后再迁移全部模块，避免页面完成后才发现权限或环境接入方式不成立。

第一版采用按需刷新、少量云函数、服务端两成员配置和手动备份；不建设权限管理后台、实时协作框架、复杂工作流或长期运维平台。外部微信通知不在首版范围，打开小程序才能看到应用内提醒。真机、密钥和控制台配置未完成时准确列为待验证，不阻塞能独立完成的实现与 review。

## 5. 可交付的验收证据

| 验收场景 | 必须满足 |
| --- | --- |
| 原生接入 | 真实 AppID 和关联环境可用；体验版关闭调试、不开代理，在两台手机的 Wi-Fi / 移动网络下完成调用 |
| 两人共享 | 任一人写入后另一人刷新可见；退出重进仍一致；两人同时首次建档不创建重复孕期 |
| 非成员与私人边界 | 第三个身份无法读写业务、上传/获取原件或调用 AI；爸爸不能借切换视角或伪造 ownerId 读取妈妈私人记录 |
| 文件权限 | 直接 SDK 访问与云函数路径分别验证，猜测 fileID、伪造报告关联、覆盖原件均被拒绝 |
| 离线与冲突 | 断网明确待同步、重启不丢输入；恢复后重试不重复；并发修改返回冲突而非覆盖 |
| AI | 未配置时显示未启用；已配置时真实验证 OCR 和 DeepSeek 成功、失败、超时和重复提交；前端产物不含密钥 |
| 迁移与恢复 | 旧记录、附件及私人边界核对；备份能恢复；正式路径不再调用旧 workers.dev 接口 |
| 小程序交付 | 包体、静态资源、拍照/相册、原件查看和切后台恢复经真实微信环境验证 |

复审新增的必验边界：

1. 超过一页的记录，拉取中途失败、分页时另一端修改，历史记录不消失。
2. 两台手机同时提交相同任务、同一操作重试及同 ID 不同内容，不重复写入或误认成功。
3. 图片未上传前重启、上传后登记前中断、原件转存后重复确认，能恢复且原件不可被客户端覆盖。
4. 冷启动离线、换微信账号、明确拒绝成员访问时，缓存不串号，未同步草稿保留在原身份范围。
5. 两人同时分析、函数超时、结果晚到、分析中删除报告，不重复写结果、不无限重试。
6. 导出到隔离环境实际恢复并打开附件；两台手机不同客户端版本仍能安全保存或明确提示升级。

ZCode 交接包含代码快照、集合/索引与安全规则、配置项名称（不含密钥）、迁移结果、验证命令与真机结果；未完成项明确标记。Codex review 不能将构建成功认定为上述场景通过。
