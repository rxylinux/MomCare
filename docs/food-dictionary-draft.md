# 饮食/安全速查词典扩充 起草稿（审阅版）

> **现状**：14 条 → 本稿扩至 **54 条**（新增 40）。
> **编写原则**（与现有词条一致）：只写有权威依据的（中国营养学会《孕期妇女膳食指南》/ NHS / FDA 孕期指南级别）；**民间禁忌不当事实写**——常见谣言（螃蟹滑胎、酱油变黑等）单独做成"澄清条目"，分级为"可以"，摘要说明"无科学依据"。
> **分级**：🟢 safe 可以 / 🟡 caution 限量注意 / 🔴 avoid 避免。
> **审阅方式**：改文件或报条目名（"删 河豚"、"皮蛋理由改成xxx"）。
> 每条的完整字段（风险详情/安全条件/来源链接/同义词）在实施时按现有 14 条格式补全，本稿先审**收录范围+分级+理由**。

## 一、新增 🔴 avoid（14 条）

| 条目 | 理由一句话 |
|---|---|
| 五分熟牛排 / 带血畜禽肉 | 未全熟肉有弓形虫与沙门氏菌风险，孕期肉类必须全熟 |
| 生腌醉虾 / 醉蟹 | 酒精+生食双风险（酒精渗透+寄生虫），属生食禁区 |
| 现挤生牛羊奶 | 未经巴氏杀菌，布鲁氏菌与结核菌风险 |
| 皮蛋（松花蛋） | 传统工艺含铅，且多为生制，孕期避免 |
| 鲨鱼 / 剑鱼 / 旗鱼等大型掠食鱼 | 汞含量高，影响胎儿神经发育（金枪鱼条目已有，本条补全名单） |
| 含酒精料理（醉鸡 / 酒糟 / 朗姆蛋糕） | 酒精无安全剂量，烹饪不完全挥发 |
| 能量饮料 | 咖啡因超量+牛磺酸等成分孕期安全性未确立 |
| 未煮熟豆芽 | 豆芽生长环境易滋生细菌，务必炒熟 |
| 未洗净的生食蔬果 / 生菜沙拉（来源不明） | 弓形虫与李斯特菌土传风险，自制需彻底清洗 |
| 霉变奶酪（蓝纹/软质霉皮） | 霉菌+李斯特菌风险（与"未经巴氏杀菌乳酪"互补成组） |
| 自行服用孕期保健品 / 中草药（含活血类） | 任何补充剂遵医嘱，红花/桃仁等活血药材孕期禁用 |
| 黄连水 / "去胎毒"偏方 | 无科学依据，新生儿黄疸与"胎毒"无关，勿给孕妇新生儿灌这类东西 |
| 高温瑜伽 / 高温运动课 | 核心体温过高有致畸风险（与温泉条目同理） |
| 清理猫砂（不戴手套不洗手） | 弓形虫主要传播途径，让别人清理或戴手套彻底洗手 |

## 二、新增 🟡 caution（13 条）

| 条目 | 理由一句话 |
|---|---|
| 浓茶（饭后即饮） | 鞣酸抑制铁吸收，与补铁错开、不泡浓 |
| 奶茶（市售） | 咖啡因+高糖双重负担，咖啡因计入每日 200mg 总额 |
| 动物肝脏 | 维 A 含量极高，少量偶尔可以（每周 ≤1~2 次、每次小块），大量有致畸风险 |
| 河豚 / 河豚制品 | 毒素无解毒剂——这条其实该 avoid，留意我最终按 avoid 落 |
| 速食快餐（高频） | 高钠高脂低营养密度，偶尔无妨、不作常态 |
| 生冷冰饮（肠胃敏感者） | 本身不伤胎儿，但腹泻诱发宫缩风险，肠胃弱者适度 |
| 深海鱼罐头（高钠型） | 鱼肉本身没问题，钠超标型选低钠款 |
| 未巴氏鲜榨果汁（鲜榨摊） | 现榨不杀菌，选正规巴氏包装或自榨即饮 |
| 辛辣火锅（卫生存疑店家） | 辣不直接伤胎儿，风险在卫生与腹泻 |
| 高海拔旅行（>2500m） | 低氧环境对胎儿影响证据不足，谨慎并咨询医生 |
| 长途自驾（连续>2小时） | 每 1~2 小时下车活动，防血栓；安全带低位贴骨盆 |
| 跳跃 / 对抗性高强度运动 | 孕中晚期重心变化易摔碰，换游泳/快走/孕妇瑜伽 |
| 体重增长过快期的精制甜食 | 配合主页"每周 0.5kg"提醒口径：控糖先砍含糖饮料与甜点 |

## 三、新增 🟢 safe（含澄清条目，13 条）

| 条目 | 理由一句话 |
|---|---|
| 全熟虾 / 全熟螃蟹 | **澄清条目**："寒凉滑胎"无科学依据，前提是彻底煮熟、新鲜、适量 |
| 豆浆（彻底煮沸） | 生豆浆含皂苷必须煮透，煮熟后是优质蛋白来源 |
| 酸奶（巴氏/正规品牌） | 益生菌+钙，冷藏链完整的正规产品放心喝 |
| 深绿色叶菜 | 叶酸+铁+钙的主力食材，每天都要有 |
| 燕麦 / 全谷物主食 | 缓释碳水+B族，替代部分精米白面 |
| 原味坚果（无霉变） | 优质脂肪+蛋白，每天一小把（约 25g）正好 |
| 当季新鲜水果（适量） | 每天 200~350g，当季优先——与每日推送口径一致 |
| 西瓜（适量） | **澄清条目**："伤胎"无据；实际问题只有糖分，控量即可 |
| 辣椒（熟制、肠胃耐受） | **澄清条目**："辣让宝宝上火"无据；孕前能吃辣的孕期照吃 |
| 酱油（正常调味量） | **澄清条目**："让宝宝皮肤变黑"无据，肤色由遗传决定 |
| 山楂（少量调味） | **澄清条目**："大量致宫缩"仅见于动物实验的极端剂量，调味量无碍；不吃浓缩制剂 |
| 游泳（卫生泳池） | 孕期最推荐运动之一，浮力护腰护膝 |
| 孕妇瑜伽 / 快走 | 中等强度运动全程有益（无禁忌症前提下） |
