# C 阶段家庭协同与双首页：编码前接口约束

状态：Codex 方案审查稿，供 ZCode 在 B3b 本地验收后实现；不是已实现或已部署声明。范围仅为一个固定家庭的两名已绑定成员。沿用 `DESIGN.md`、`PRD.md`、`REMAINING_PHASE_ACCEPTANCE.md` 的页面和验收要求，不扩展邀请、社交关系或多租户后台。

## 身份与展示

- 服务端从可信微信身份解析 `familyId/memberId`；请求中的角色、视角、作者、负责人字段都不能用于提升权限。默认视角是**本人偏好**，两位成员都能切换两种首页排序，切换不改变本人身份、私人数据范围或代记录的 `recordedBy`。
- 首页采用现有孕期、健康、产检、报告、待产包的权威数据。分享卡、共同任务分别取各自的权威集合；不得从私人心情自动生成分享，也不得用演示值补空状态。所有入口在两种视角都可达；未实现的 E 类工具暂不标成可用。
- 今天的判定按家庭时区 `Asia/Shanghai` 的日期键执行；过期分享进入历史，不因本地时间或离线缓存冒充今日。同步状态与健康含义分开显示。

## 分享与任务的最小服务端合同

1. 分享由用户显式确认的短句和可选目标日期构成。创建、编辑、结束、撤回只允许作者；原文不复制到个人笔记、操作回执、任务标题、索引或日志。响应只返回当前授权可见的投影视图。服务端限定长度、日期和字段白名单，并使用 `expectedRevision`、稳定 `operationId` 与可信操作者。
2. 分享状态为 `active/closed/withdrawn`。撤回是单调墓碑：保留 ID、版本、作者与撤回时间供同步清理，移除正文；旧版本编辑、旧离线创建重放和分页旧响应不得恢复正文。客户端在收到更高版本墓碑时，清理当前分享、搜索索引及派生任务文案；分页不完整时不根据“列表缺失”推断撤回。
3. 每个来源至多一个关联任务。分享来源的稳定任务 ID 由 `familyId + sourceType + sourceId` 确定；产检/待产包沿用各自稳定来源 ID。`接下这件事` 在单事务中检查分享仍 active、校验修订、创建或读取该唯一任务并记录真实操作者。重复点击、并发两端与丢响应重试必须返回同一任务；同一个 `operationId` 携不同请求摘要必须拒绝。
4. 被指派的负责人和主动接下的 `acceptedBy/acceptedAt` 分开。任务状态 `pending/doing/done/cancelled` 的每次修改保留版本、操作者和时间。来源为产检或待产包时，完成状态以一个权威实体为准；另一页面只展示其投影，不能形成两份独立进度。
5. 分享来源的任务不持久复制分享正文。显示文案从**当前 active 分享**按需生成；若撤回，任务在同一事务内转为 cancelled 或无原文的结束记录。历史 `operationId` 回执只保存请求摘要、实体 ID 和不含正文的结果元数据；重放必须重新按当前分享状态生成脱敏响应。旧客户端已复制的标题在服务端迁移/读取投影中清空，且不允许其旧版本再次写回。
6. 导出、列表、详情、搜索、冲突响应及错误都经同一授权和撤回投影。对已经下载或离线看过的副本，只说明联网同步后清理本应用缓存，不承诺远程即时抹除。

## 本地与失败语义

- 新分享及任务写入先落成员和家庭作用域的持久 outbox；落盘失败则不发云请求、不显示“已保存”。网络发送失败保留输入和原 `operationId`；不确定成功以同 ID 重试。身份切换、冷启动和异步迟到响应受 session epoch 约束，不把前一身份快照带到后一身份。
- 逐集合完整分页成功后才推进同步水位；冲突时展示本地输入与服务端当前版本，用户作选择前不得静默丢弃输入。分享撤回与旧客户端待办冲突时服务端墓碑优先，客户端保留可供本人处理的本地草稿，但不得再次发送已撤回原文给对方。
- 所有读取路径验证两个固定成员及所属家庭；第三身份不得看到数据、成员是否存在、分享正文、任务标题、缓存或导出。私人 canary 在列表、详情、首页、搜索、AI 上下文、导出及冲突响应中都不得泄漏。

## 独立验收门

- TESTING 用两名真实模拟身份走页面 `妈妈显式分享 → 爸爸接下 → 完成/撤销完成`，证明两视角可切换但权限不变；验证空、长文本、目标日期跨上海午夜、离线和冷启动。
- 注入同源任务双端并发、同 `operationId` 重放与改体重放、事务后丢响应、撤回与接单/导出/分页/旧 outbox 竞态，逐步核对服务端文档数、任务 ID、状态和各响应正文。撤回后的任何服务端响应不得再含原短句；两端缓存重新联网后应消除该短句。
- 产检与待产包各造一项来源任务，重复创建和反复完成不复制任务也不分裂进度。两名成员分别放置私人 canary，第三身份探测所有读写入口；实际 `mp-weixin` 页面入口、按钮及持久化路径须一起验收。此门通过后才提交/推送 C 阶段；真实 CloudBase 部署仍留到全部本地阶段完成。
