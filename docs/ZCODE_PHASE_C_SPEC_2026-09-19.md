# C 实施交接：两种首页、分享需要、共同任务

状态：Codex 方案准备。B3 验收提交后启动；沿用 PRD、DESIGN 与已验收同步/附件/导出协议，不提前部署或启用 AI。ZCode 编码，Codex 独立 review。

## 页面与身份

改造现有 `pages/index/index.vue`，不另建孤立“爸爸模式”页面。妈妈视角按孕期概览→今日记录→分享需要→产检→共同准备排序；爸爸视角按孕期概览→对方主动分享→我负责的事→陪诊准备排序。所有已实现工具双方都能进入，完整健康指标仍可查看。

首页顶部和“我的”提供默认视角设置，按当前可信成员隔离持久化。切换只改变排序与默认展开，绝不修改当前身份、CloudBase 调用者、作者或私人记录范围。无配置/未确认/演示仍遵守现有明确状态；不要因新首页隐藏原记录、产检、待产包、报告入口。

## 主动分享

独立编辑器只接受用户输入并确认的共享短句与目标日期；不自动复制私人心情/症状/备注、健康指标或 AI 推断。提交前标“对方可见”，成功后表示已同步或已排队，不暗示推送/已读。

分享含稳定 ID、作者、日期、文本、open/ended/withdrawn 状态、revision 与服务端操作者/时间。只有作者可编辑、结束或撤回表达；另一成员只可接下关联行动。空文本拒绝，按真实上海日号区分今日和历史，不把昨日状态或无记录解释成今天心情。

撤回需清除未来接口、关联任务、冲突响应和幂等结果中的正文；不能只从首页隐藏。已下载的离线副本无法承诺立即远程擦除，沿用 DESIGN 的准确说明。实现时列出所有复制正文的位置并优先避免重复存储；任务可通过来源 ID 读取有效表达，撤回后显示不含原文的结束状态。

## 任务与来源一致性

一项需求至多一项关联任务：以受控稳定来源映射和事务保证创建/接下唯一；不能先查列表再随机写两条。稳定操作 ID、旧 revision、离线队列、确认目标状态必须保留；用户重试同一草稿不能新建实体，确认重提不能反转原本目标状态。

任务含标题、可选约定日期、负责人、状态 pending/doing/done/cancelled、来源、revision、实际操作者和时间。指派不代表已接受。支持接下、开始、完成、撤销完成和取消；成员身份由服务端决定，不因 assignee 字段改变权限。任务编辑也捕获表单打开时的版本。

来源为待产包/产检时复用同一稳定实体，不复制第二套完成进度。ZCode 先明确每种来源的完成/撤销/取消如何作用于原实体，采用原子更新或明确的单一权威推导；双方从任一入口修改后都一致。仅调整数量/位置不能误改完成人。来源删除、需求撤回时任务清除对应敏感原文，旧待办不能重建已结束来源。

## 页面细节与共享组件

- 需求卡注明真实作者、日期、正文、关联任务；按钮在接下后变为查看任务，重复点击不会再创建。
- 共同任务列表和“我负责的事”来自同一 store；提供筛选/空态、失败重试、冲突比较、采用云端/确认重提与已完成历史。
- 产检详情按视角默认展开检查问题或陪同材料，访问同一记录；不限制另一视角查看。
- 已有知识库按孕周/视角排序，展示真实来源/更新时间；没有审校证据不新增医生认证或医学保证。未验收的计算器不做空壳入口。
- 长文本换行、字号放大、键盘和安全区、微信胶囊位置纳入实际页面检查；保留现有暖色风格，不按性别做两套皮肤。

## 冻结与验收

先列覆盖矩阵：每项需求对应实际组件/处理器、服务端动作、长期测试和独立验证入口。不得把导入、接口存在或窄探针绿色当成页面完成。

合成双成员完整走“妈妈私人记录→单独分享需要→爸爸接下→完成→撤销完成→作者撤回”，检查当前接口、缓存、outbox、冲突、历史重放及 B3 导出。验证双端接下竞争、断网重复点击/冷启动重试、改日期/跨午夜、撤回与接单/导出交错；私人 canary 在另一身份的全部响应中不可见。两成员都切换两种视角并验证权限不变。

验证来源任务双向一致和删除后不复活；完整执行受影响的前阶段回归与双端构建。冻结列全部源码/测试哈希，通过后提交推送。外部推送、真实平台验收和供应商 AI 仍统一留最终部署。
