# B3a 实施交接：旧来源确认与可恢复迁移

基线 `e0cf22f19ece03001d6f2446993805de27b0184e`。B3a可独立开始，B3b包格式/备份/隔离恢复尚待设计收尾；不要实现B3b云集合或恢复文件引用。合成数据开发，真实旧数据不读、不迁移；ZCode编码，Codex review后提交。

## 页面与范围

- 在privacy.vue提供真实“旧数据来源预览”入口，新增data-source-scan页。privacy的当前数据/同步统计用可信会话与familyStore；来源旧键仅显式进入扫描时读取。未确认/退出/演示不展示正式成员缓存或默认执行扫描。
- 白名单：YUNTU_HEALTH_DATA、YUNTU_REPORTS_DATA、hospital_bag_items，以及已有MOMCARE_BACKUP_HEALTH_/REPORTS_前缀。只枚举键名筛前缀，不遍历读取其他值。读失败、JSON损坏、未知schema显示独立错误，不当空来源。
- 完整原始来源只留本机，不改旧键、不删除旧附件。需要补备份时先确认备份写成功；失败不迁移。原始源中的openid、ownerTokenFingerprint、token、AI旧配额/结果等不进入预览正文、迁移payload、日志或未来业务备份包；迁移严格字段白名单。
- 预览明确每个来源的类别/数量、示例标记、日期/单位/类型错误、无法迁入的字段、缺失附件、重复/冲突。已知origin=demo或演示标记不允许当真实数据自动上传；未知来源保持未确认。用户可选择具体领域/条目，不是只按一个“我已确认”全库上传。

## 字段映射与确认

- 健康records[date]的weight→weightKg，bp合法收缩压/舒张压→systolic/diastolic，fetal→fetalCount；零值按领域规则保留。非法/不明单位或日期不可猜测转换，保留待处理。
- mood/symptoms/note/plans默认私人，仅当前本人显式确认作者后迁入本人mood域；绝不默认把旧note映射sharedNote。旧token指纹或OpenID不能替代CloudBase身份。孕期资料映射当前pregnancy已支持字段。
- 报告report_type/report_date/notes/归档状态映射新schema，附件保持全部原件和页序。仅授权可读的本机实体或当前受控云引用可用；旧HTTP/未知cloud fileID/丢失路径不自动下载，不伪造完整迁入。用户可重选缺失原件且重新确认映射；报告notes共享必须在预览中明确。
- 旧产检安排/待产包如存在可识别schema按当前checkup/bag支持字段映射；无稳定旧ID须制定可复现sourceId。不支持结构原样保留隔离并提示，不能默默当已迁完。
- 同源原键与备份中相同实体只预览一次（保留来源列表）；同ID不同正文不任意覆盖，要求明确选取；实体身份与内容摘要分开，不因改正文就制造另一条同源目标。

## 持久意图与执行

1. 确认绑定env/AppID/family/member、源原始值摘要、逐条共享/私人选择与目标字段。实体内容或来源变化重新预览，不能沿用旧确认。
2. 持久批次记录每条稳定sourceId/targetId/operationId、规范化payload摘要、expectedRevision、附件原始来源及uploadId/fileId映射、执行状态。首次网络/文件移动前写成功；失败不发送。
3. 重启后同成员重新确认身份，源摘要不变则从原批次继续；另一成员不可读/执行旧成员批次。请求期间以开始epoch为准，任意await后及下一条副作用前检查。
4. 复用既有outbox与handler幂等协议。若现有familyStore接口不能传稳定operationId，应设计一个小而明确的入口扩展，不另造不受审查的裸HTTP/自动云写通道。入队内容不可变，已发送操作不能被重写或换ID；来源变更重新预览不篡改仍待对账的旧请求。
5. 首次迁入以创建基线0；已有/较新/已删实体冲突时明确保留，不自动采用当前revision覆盖。共享日期已有记录需提示冲突，而不是强行覆盖。重复确认同一来源、源键与备份重复选择、断网/丢响应/重启均不重复创建目标。
6. 分项成功/失败/待同步/冲突真实展示，有可到达的继续处理入口；云端已确认但本机完成标记落盘失败仍可对账，不能丢弃原始输入。回退或退出不清掉已保存的迁移批次。
